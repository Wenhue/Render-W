# Render W — GitHub edition

Windows x64 render queue for Cinema 4D and After Effects, with checkpoints, automatic retries, output validation and per-frame timing charts.

Download the complete ZIP from **Releases**, extract it and run `Render W.exe`. Windows 10/11 x64 and a working local C4D/AE installation are required. Renderer licensing remains with its vendor.

The interface automatically uses Simplified Chinese for a Chinese Windows language and English otherwise. You can select System default, 简体中文 or English in Settings. Help includes a bilingual user guide. Project filenames and renderer logs keep their original language.

This edition is separate from the stable edition: settings, task history, monitor plugin and update channel are independent. Automatic updates use the existing update server through a dedicated GitHub channel. Until that channel is published, manual update checks report no available update.

This repository is intended for compiled distribution assets and documentation. Render W is not being released under an open-source license. Third-party dependency licenses remain applicable. Downloads are provided as ZIP assets on the Releases page.
