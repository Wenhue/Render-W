# Render W v1.7.30

Render W is a Windows render queue manager for Cinema 4D (C4D) and Adobe After Effects (AE). Add multiple projects to one queue, control rendering, track progress and review completed results.

## Main features

- Organize render jobs and change the order of waiting tasks.
- Start, pause, resume and cancel queue jobs.
- Recover unfinished jobs from checkpoints and retry failed rendering.
- Preview outputs and view per-frame render-time charts for image sequences.
- Receive email notifications with task results.
- Use English or Simplified Chinese, selected automatically from the Windows language or manually in Settings.

This GitHub build keeps its settings, task history and update channel separate from the main edition. Automatic updates use a dedicated channel on the existing server. That channel is not live yet; use GitHub Releases for manual downloads until it is enabled.
